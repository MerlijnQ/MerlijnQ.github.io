Development of an architectural design descision (ADD) classifier using a small debertaV3 backbone (44M parameters). We developed both an binary ADD classifier (classify whether a Jira Issue is an ADD) and a multilabel classifier (if ADD is predicted, also predict the kind of ADD). The model was developed using Jira issues from different collections. Data cleaning was critical due to the noise in the dataset presented my various model names, specific error codes and more. Development was done in a dockerized fashion with a full CI/CD pipeline. Final model deployment was done using asynchronous modules in fastAPI. Final results on a held out test set can be see in [Table 1](#table_1). A system overview and the CI/CD pipeline can be seen in [Figure 1](#fig:c5) and [Figure 2](#fig:cicd).


<a id="table_1"></a>

| Metric     | Binary | Multilabel |
|------------|--------|------------|
| Accuracy   | 0.79   |     0.80   |
| Precision  | 0.77   |     0.71   |
| F1         | 0.79   |     0.74   |
| Recall     | 0.81   |     0.77   |

Table 1: Results overview.
